Collections

What's in the store

Data are grouped into collections, one per top-level folder. A collection holds datasets, such as the ESA land-cover maps, and a dataset holds the products derived from it, such as their SEALS reclassification. Each dataset page lists every file with its version, size, resolution, licence and source, and how it was made, from the raw download to the published POG.

Pyramidal Cloud-Optimized GeoTIFFs

One lattice, every resolution, exact at each.

Every raster sits on a rung of one fixed ladder of nested global grids, from 10 arcseconds to 180 degrees, with bit-identical geotransforms. Its overviews are the coarser rungs, aggregated by the rule its kind of data needs.

  • Σ

    Totals that add up

    Hectares, tonnes and people are summed up the ladder, so every coarser cell holds the exact total beneath it.

  • ▦

    Any window, any rung

    Read a country at 5 arcminutes or a watershed at 10 arcseconds over HTTP, fetching only the bytes it covers.

  • ✓

    Checked before it's published

    Each file passes the POG validator, carries exact statistics, and is hashed into a versioned release.

Get the data

A URL is all you need.

Every file's current version is served at https://data.teemlabs.org/<ref path>, the same ref path the devstack's code uses. Download it whole, or read just a window of it in place.

import rasterio
from rasterio.windows import from_bounds

url = "https://data.teemlabs.org/%%EXAMPLE_REF%%"
with rasterio.open(url) as src:
    window = from_bounds(-97.5, 43.5, -89.5, 49.5, src.transform)  # lon/lat box: Minnesota
    data = src.read(1, window=window)                               # fetches only these tiles
# Inspect it in place, then cut a lon/lat window without downloading the rest
gdalinfo /vsicurl/https://data.teemlabs.org/%%EXAMPLE_REF%%
gdal_translate -projwin -97.5 49.5 -89.5 43.5 \
  /vsicurl/https://data.teemlabs.org/%%EXAMPLE_REF%% minnesota.tif
# The whole file
curl -O https://data.teemlabs.org/%%EXAMPLE_REF%%

# What the latest release contains
curl https://data.teemlabs.org/_release/latest.json

In devstack code, refer to the ref path (p.get_path("%%EXAMPLE_REF%%")): a project then runs on any machine.

Versions

The newest at a plain path; the past kept beside it.

A dataset is updated by publishing a release: every file in it is gated, hashed and committed together, or not at all.
